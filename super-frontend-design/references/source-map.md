# Source map

This unified skill consolidates the downloaded repositories in the parent workspace.

- `frontend-design-pro`: product-first workflow, visual direction, copy discipline, accessibility, responsive layout, and verification.
- `impeccable`: design commands, critique/audit/polish workflow, anti-pattern detection, and finishing discipline.
- `taste-skill`: brief inference, design variance/motion/density dials, anti-slop rules, redesign protocol, and production guardrails.
- `emilkowalski-skills`: animation decision-making, easing, springs, gestures, performance, component responsiveness, and strict review.
- `ui-ux-pro-max-skill`: product/industry matching, style/color/type recommendations, chart guidance, stack-specific rules, and design-system generation.
- `npxskillui`: static and browser-assisted extraction of existing sites and codebases into tokens, screenshots, references, and an agent-readable skill.

Use the source repositories as references, not as competing system prompts. This skill owns the workflow and conflict resolution; consult a source file only when its specialized detail is needed.
